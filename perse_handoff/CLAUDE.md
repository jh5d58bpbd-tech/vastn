# CLAUDE.md — 内装パース制作プロジェクト

このフォルダは、Claude（チャット）で進めてきた内装パース制作の引き継ぎ一式です。
**作業を始める前に必ず `README.md` を全部読むこと。** 案件の経緯・確定仕様・未確定事項・座標系はすべてそこにある。

**素材・色・照明を決めるときや修正案を出すときは、`knowledge/design_color_notes.md`（木目トレンド・人気カフェの原則・色彩の基礎）を判断基準にすること。** ユーザーはデザインの追求にこだわりがあり、芸術が好き。

## 現在の主案件
中外テクノス 1階 スタッフルーム（休憩室）リフォームのパース。シーンは `render/kyuke.py`、最新画像は `renders/kyukei/`。

## 作業ルール
- ユーザーは日本語で話す内装・設計の担当者。返事は日本語で、専門用語（ジプトーン、ダイノック、巾木、ふかし壁など）はそのまま使ってよい。
- **標準のレンダラーは Blender Cycles（`blender/`）**（2026-11 ユーザー承認）。自作レンダラー（`render/run_kyukei.sh`）は予備。
- 修正の流れ：`render/kyuke.py`（またはデザイン案は `render/variants.py`）を編集 → **試し描き `blender/run_kyukei_cycles.sh 480 300 32`** で確認（自分で画像を見て破綻がないか確認）→ ユーザーに見せる → OK なら本番 `blender/run_kyukei_cycles.sh 1440 900 128`（4コアで1面約10分）。
- **ユーザーに見せる画像は新しい絵だけ。** 変更前の画像を並べた比較画像は作らない（ユーザー指示）。
- 走っているシェルスクリプトは編集しない（bash が途中から読み直して壊れる）。
- 図面（`refs/kyukei/01_改修プラン_図面3枚.pdf` の2枚目＝1階改修後）と仕上げ表・手書きメモが正。迷ったら図面と現況写真を見直し、それでも曖昧なら解釈を一言添えて進めるか、ユーザーに確認する。
- 承認済みの画角（`VIEWS`）は、頼まれない限り変えない。新しい画角は追加で作る。
- 指示を反映したら `README.md` の「6.3 確定している仕様」「6.5 修正の経緯」「6.6 未確定事項」を更新する。
- 座標：単位 m、x=東、y=上、z=南、原点=北西の室内角。カメラ yaw 0 = −z（北）向き。

## ビルド・実行
```bash
pip3 install -r render/requirements.txt
cd render && ./build.sh          # macOS で OpenMP が無い場合は brew install libomp か brew install gcc を推奨
./run_kyukei.sh 480 300 24        # 試し描き
```
