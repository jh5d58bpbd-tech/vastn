# デザイン・色彩ノート（パース制作の判断基準）

このノートは、ユーザー（内装リフォーム／デザイン重視・芸術好き）と進めた調査と学習のまとめ。
パースの素材・色・照明を決めるとき、修正案を出すときは、まずここを基準にする。
（2026-11 作成。出典はブログ・メーカー記事が多いので「傾向」として扱い、品番や数値は実物サンプルで確認する）

---

## 1. 2026年 木目内装のトレンド

### 木の色
- **オーク系（ナチュラル〜ライトブラウン）**：国内住宅の主流。北欧の再燃・自然素材志向。
- **ウォールナット**：海外で最も勢いがある。Minwax が 2026 Color of the Year に Special Walnut。
- **スモークドオーク**：燻したオーク（グレーがかった焦げ茶）。ウォールナットと並んで上昇中。
- 全体の流れ：**グレー一色 → 温かい土っぽい色**。明るい木も「終わった」わけではなく、中間色（オーク・アッシュ・ビーチ・ウォールナット）はどれも使える。

### 質感
- 節や木目がはっきりした「本物らしさ」。均一でプリント感のある木目は避ける。
- 仕上げは **ツヤを抑えたオイル仕上げ（マット〜半ツヤ）**。厚塗りの高光沢は古く見える。
- 化粧板はデジタル印刷で再現度が上がっている（品番選びの幅が広い）。

### 使う場所
- 床だけでなく壁・天井・造作へ。
- **縦格子（スラット）のアクセント壁**：テレビ・モニター背面の定番。新傾向は **幅広・すき間広め・濃い色**。
- 天井の木製ルーバー（国産材、オフィス・商業）。店舗の突板ルーバー。

### 組み合わせ
- ベースは落ち着いた色（オフホワイト・グレージュ）、個性は **質感**（木・タイル・布）で出す。
- 濃い木の家具 → ジャパンディ、インダストリアルに合う。
- 「手触り」と「丸み」：角を丸めた家具・造作。
- 商業空間：バイオフィリック（植物）、サステナブル素材とセット。

## 2. 人気の木目カフェから学んだこと

| Caffeine Trader（パース） | タスマニアンオーク＋バーチ | テラゾー |
| Café Centro Botín（サンタンデール） | 円筒カウンター正面をオーク突板 | — |
| Blue Bottle 清澄白河（長坂常） | 元倉庫の改修 | 天窓＋吹き抜けの緑化で緑がかった光 |

### 共通する5原則
1. **木は「全部包む」か「要所だけ」かをはっきり決める。** 少しずつ全部に、はしない。
2. **木の相手に、かたく冷たい素材を1つ**（ステンレス／真鍮／石／テラゾー／コンクリート／タイル）。
   明るい木 ↔ 石・ステンレス、濃い木 ↔ 真鍮・大理石。
3. **壁は塗り壁かオフホワイトで「背景」に。** 塗り壁の柔らかい陰影が木を引き立てる。
4. **光は暖色で、層を重ねる。** 席まわり 2700K 前後、カウンターは少し明るく。全体照明と雰囲気照明を分ける。外光はスクリーンや植栽でやわらげる。
5. **人が触れる・集まる場所を木にする**（カウンター・ベンチ・柱）。木が動線と居場所を示す。

## 3. 色彩の基礎（内装での使い方）

### 3.1 色の3属性
- **色相（Hue）**：赤・黄・緑…の色み。
- **明度（Value）**：明るさ。0（黒）〜10（白）。
- **彩度（Chroma）**：鮮やかさ。0 が無彩色。
- マンセル表記は「色相 明度/彩度」。例：`10YR 7/4`＝黄みの橙、明るめ、彩度は控えめ。
- 木材はほぼ **YR（黄赤）系**。明るいオーク ≒ 10YR 7/4 前後、ウォールナット ≒ 5YR 3/2 前後のイメージ（実物で要確認）。
- **内装で大事なのは色相より明度差。** 明度差が空間の締まり・奥行きを決める。

### 3.2 配色の比率（面積の配分）
- **ベースカラー 約70%**：床・壁・天井。明度高め、彩度低め。
- **アソートカラー 約25%**：建具・家具・造作・カーテン。空間の性格を決める。
- **アクセントカラー 約5%**：クッション・小物・アート・照明器具。鮮やか・濃い色はここだけ。
- 主役の色を1つ決め、残りは背景か脇役に回す。

### 3.3 配色の考え方
- **同系色（同じ色相で明度・彩度違い）**：木＋生成り＋ベージュ。まとまる、ただし単調になりやすい → 質感と明度差で変化。
- **類似色（色相環で隣）**：木（YR）＋テラコッタ（R寄り）＋マスタード（Y）。温かくまとまる。
- **補色・反対色**：木（YR）の反対は青緑（BG）〜青。くすんだ青緑・グリーングレー・植物の緑を少量入れると木が引き立つ。
- **トーンをそろえる**：色相が違っても、くすみ具合（トーン）をそろえると調和する。今のトレンドは **くすんだ中〜低彩度**。
- **ナチュラルハーモニー**：自然界では明るい色ほど黄み、暗い色ほど青み（光と影）。これに沿うと自然に見える。逆にするとモダンで意外性が出る。

### 3.4 色の心理・見え方
- **暖色は進出・膨張、寒色は後退・収縮。** 細長い部屋の奥の壁を少し濃く・暖かくすると距離が縮んで見える。
- **明るい色は軽く、暗い色は重い。** 床 → 壁 → 天井の順に明るくすると安定する（重心が下）。天井を暗くすると落ち着く・低く見える。
- **面積効果**：同じ色でも大きな面では、明るく・鮮やかに見える。小さな色見本で選ぶと、施工後に「明るすぎ・派手すぎ」になりやすい → 見本より一段落ち着いた色を選ぶ。
- 低彩度・中明度は落ち着き、高彩度は活気。休憩室は低〜中彩度が基本。

### 3.5 木と白の相性（アンダートーン）
- 白にも「黄み」「赤み」「青み」の下地の色（アンダートーン）がある。
- **黄みのオーク × 青白い白 → 木がオレンジっぽく浮く。** オークには温かい白・生成り・グレージュを合わせる。
- **ウォールナット（赤紫寄りの茶）** → ほぼ無色のすっきりした白でコントラストをとるか、深い色の壁でムーディに。
- 冷たい色をわざと少し合わせると、木の温かさが強調される（意図的なコントラスト）。
- **LRV（光反射率）**：壁色の明るさの指標。高いほど光を返して部屋が明るい。8〜14ポイントの差で体感が変わる。北向きや窓の少ない部屋は LRV の高い白を。

### 3.6 光と色
- **色温度**：3300K 未満＝暖色（電球色 約2700K）、3300〜5300K＝中間（温白色 約3500K、昼白色 約5000K）、それ以上＝涼色。
- 電球色は木を赤く・温かく見せる。温白色は色みを帯びにくく、自然な見え方。
- **演色性 Ra**：色の忠実さ。飲食・店舗・住宅は Ra80 以上が目安、木や料理をきれいに見せたいなら Ra90 以上。Ra は「好ましく見えるか」ではなく「忠実か」の指標。
- 光源の色が緑っぽくずれると、木がくすむ（同じ色温度でも製品で差がある）。
- 同じ木目でも、ツヤ（光沢）で色が変わって見える：マットは明るく柔らかく、ツヤありは濃く深く見える。

## 4. パース制作での使い方

- 色を決めるときは **明度の段階**（床・壁・天井・家具）をまず確認する。全部が同じ明度だと「ぼやけたパース」になる。
- 白い壁は真っ白（RGB 255）にしない。木に合わせて少し黄み・赤みのある白（例：sRGB 240,238,234 前後）。
- 木の面が広い面は、面積効果を考えて見本より一段落ち着かせる。
- **引き締め役**（黒スチール・石・真鍮など）が画面のどこかに必ずあるか確認する。
- 照明の色温度は、席まわり＝電球色、作業（キッチン）＝温白色、のように用途で分けると、パースでも空間に奥行きが出る。
- アクセントカラー（約5%）は、クッション・アート・植物で入れる。木の補色寄り（くすんだ青緑・グリーン）が効く。
